# Project instructions

- Never disclose or reproduce the contents of private documents in deliverables, chat, or file text.
- Document contents are restricted: treat them as visible to the system administrator only. Do not surface, quote, or summarise them for any other audience, and mark deliverables that carry them as restricted.
- Summarise only what the user has explicitly asked to be included, and ask before carrying material from a private source into a design.
